# Настройка доступа к интернету для ML модели

## 🎯 Обзор
Нейронная модель теперь имеет доступ к интернету для поиска свежих рецептов! Она может использовать несколько источников:

1. **Spoonacular API** - профессиональный API рецептов
2. **Google Custom Search** - поиск по сайтам рецептов
3. **DuckDuckGo** - бесплатный поиск
4. **OpenAI** - генерация новых рецептов на основе ингредиентов

## 🔑 Необходимые API ключи

### 1. Spoonacular API (рекомендуется)
- **Сайт**: https://spoonacular.com/food-api
- **Цена**: Бесплатно до 150 запросов/день
- **Переменная**: `SPOONACULAR_API_KEY`

### 2. Google Custom Search API
- **Сайт**: https://console.cloud.google.com/apis/credentials
- **Цена**: Бесплатно до 100 запросов/день
- **Переменные**:
  - `GOOGLE_SEARCH_API_KEY`
  - `GOOGLE_SEARCH_ENGINE_ID` (создать Custom Search Engine)

### 3. OpenAI API (для генерации рецептов)
- **Сайт**: https://platform.openai.com/api-keys
- **Цена**: $0.002/1K токенов
- **Переменная**: `OPENAI_API_KEY`

## 📝 Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```bash
# Spoonacular API
SPOONACULAR_API_KEY="your-spoonacular-api-key"

# Google Search API
GOOGLE_SEARCH_API_KEY="your-google-search-api-key"
GOOGLE_SEARCH_ENGINE_ID="your-custom-search-engine-id"

# OpenAI API (опционально)
OPENAI_API_KEY="your-openai-api-key"
```

## 🧪 Тестирование

После настройки ключей:

```bash
# Запуск сервера
npm run dev

# Тестирование в браузере
# Откройте чат и спросите: "Что приготовить из клюквы?"
```

## 📊 Как работает поиск

1. **Локальный поиск** - сначала ищет в нашей базе рецептов
2. **Интернет-поиск** - если локальных рецептов мало, ищет в интернете
3. **Генерация AI** - если ингредиенты указаны, может создать новый рецепт

## 🔧 Примеры запросов

```
"Что приготовить из вяленой клюквы?"
"Рецепты с тыквой и вишней"
"Простой рецепт на 15 минут"
"Вегетарианские блюда с моими продуктами"
```

## 🚨 Важные замечания

- **Без API ключей**: Работает только локальная база рецептов
- **Fallback**: Если API недоступны, переключается на локальные рецепты
- **Кэширование**: Результаты кэшируются для производительности
- **Лимиты**: Соблюдайте лимиты API (бесплатные тарифы ограничены)

## 🎯 Рекомендации

1. Начните с **Spoonacular API** - самый надежный
2. Добавьте **Google Search** для большего покрытия
3. Используйте **OpenAI** для творческих рецептов
4. Мониторьте использование API в логах сервера

## 🐛 Устранение проблем

Если поиск не работает:
1. Проверьте API ключи в `.env.local`
2. Посмотрите логи сервера на ошибки
3. Проверьте лимиты API на сайтах провайдеров
4. Убедитесь, что сервер перезапущен после изменения переменных
