# Настройка Supabase для Magic Berry

Ваш проект настроен для работы с Supabase (PostgreSQL). Prisma ORM будет автоматически управлять структурой базы данных.

## 1. Получение доступов в Supabase

1. Создайте проект на [database.new](https://database.new).
2. Перейдите в **Project Settings** -> **Database**.
3. В разделе **Connection Pooling** (или Connection String):
   - Скопируйте URI для **Transaction** (порт 6543) — это ваш `DATABASE_URL`.
   - Скопируйте URI для **Session** (порт 5432) — это ваш `DIRECT_URL`.
4. Вставьте эти значения в файл `.env` (создайте его на основе `.env.example`).

## 2. Применение схемы (Создание таблиц)

Вместо ручного ввода SQL, запустите эту команду в терминале. Она создаст все таблицы, индексы и связи автоматически:

```bash
npm run db:push
```

## 3. Как получить чистый SQL (опционально)

Если вы хотите увидеть или сохранить SQL-запросы, которые выполнит Prisma (например, чтобы запустить их через SQL Editor в Supabase), выполните следующие шаги:

1. Убедитесь, что в `.env` заполнены ссылки на базу.
2. Запустите команду:

```bash
npx prisma migrate diff --from-empty --to-schema-datamodel prisma/schema.prisma --script
```

Эта команда выведет в консоль полный SQL скрипт (`CREATE TABLE`, `CREATE ENUM` и т.д.), который соответствует вашей схеме.

## 4. Просмотр данных

Чтобы просматривать и редактировать данные в удобном интерфейсе:

```bash
npm run db:studio
```

## 5. Важные заметки для деплоя (Vercel)

- Не забудьте добавить переменные `DATABASE_URL` и `DIRECT_URL` в настройках проекта на Vercel.
- При деплое Vercel автоматически сгенерирует Prisma Client (`prisma generate`).
- Миграции (`db:push`) лучше запускать локально с вашего компьютера перед деплоем изменений схемы.
